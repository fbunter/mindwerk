# Mindwerk

Ein Mindmap-Editor, der komplett im Browser läuft – ohne Anmeldung und ohne Server.

- Strukturen: Mindmap, Logikdiagramm, Organigramm, Baumdiagramm, Zeitstrahl
- Notizen, Links, Labels, Marker, Farben, Designs, Beziehungslinien
- Gliederungsansicht und Präsentationsmodus
- Import/Export: XMind (.xmind), Markdown, OPML, JSON, PNG, SVG

Die Maps werden lokal im Browser gespeichert (localStorage). Für Sicherungen die Export-Funktion nutzen.
